# Design System: n8n AI Workflow Client

<!-- impeccable:design-schema 1 -->

## Visual World

A tactile, cybernetic authentication console built for automation engineers and AI creators. It balances dark neutral canvas layers with vivid n8n brand orange (#ff6b4a), electric cyan (#38bdf8), and emerald (#10b981) status indicators.

## Typography

- **Interface Primary**: `Manrope` (weights: 400, 500, 600, 700, 800) for clean legibility, modern hierarchy, and crisp headers.
- **Code & Telemetry**: `JetBrains Mono` (weights: 400, 500, 600) for endpoints, tokens, status codes, latency metrics, and JSON response bodies.

## Palette Tokens

- `--bg-base`: `#090c13` (Deep charcoal obsidian background)
- `--bg-card`: `#101622` (Card surface background)
- `--bg-input`: `#080b11` (Recessed dark input field background)
- `--accent-primary`: `#ff6b4a` (n8n signature warm orange)
- `--accent-cyan`: `#38bdf8` (Electric sky cyan for secondary highlights)
- `--accent-emerald`: `#10b981` (Vibrant green for confirmed 200 OK responses)
- `--accent-rose`: `#f43f5e` (Red-rose for failed connection or error status)

## Micro-Interactions & States

1. **Clean Card**: Subtle top border gradient with neutral elevation.
2. **Tactile Button**: High-contrast button with hover state, active scale, and loading spinner animation.
3. **Response Alerts**: Inline alert banners for green success and red error states.
