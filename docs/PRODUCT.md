# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain modern HTML, Vanilla CSS, and JavaScript (no heavy build tool)

## Users

Creators, developers, and automation builders who want a clean, responsive interface to trigger n8n image generation workflows, tweak parameters/prompts, and inspect/manage generated visual outputs.

## Product Purpose

Provide an interactive web UI and dashboard for generating, previewing, and managing images orchestrated through n8n automation workflows, bridging webhook execution with a polished user experience.

## Positioning

A lightweight, zero-bloat web client interface directly integrated with n8n backend webhooks for real-time prompt dispatch, status tracking, and gallery review without requiring complex server infrastructure.

## Operating Context

Browser-based web client running locally or hosted as a static interface, communicating with an n8n workflow engine via webhook/REST endpoints to trigger image creation models and stream or poll results.

## Capabilities and Constraints

- Prompt input with configurable parameters (style, aspect ratio, model choice, negative prompts).
- Webhook integration to dispatch requests directly to n8n endpoints.
- Gallery or viewport to preview, compare, download, and manage generated image assets.
- Responsive, lightweight client using vanilla HTML/CSS/JS with zero build overhead.

## Brand Commitments

Clean, modern dark-mode aesthetic with fluid interactions, crisp typography, and intuitive workflow controls.

## Product Principles

1. **Zero-friction generation**: Prompt submission and webhook dispatch should feel instant and tactile.
2. **Transparent workflow feedback**: Clear visual states for pending, generating, failed, and completed webhook runs.
3. **Asset-first focus**: Visual outputs take center stage with high-fidelity preview, zoom, and export options.
4. **Lightweight and resilient**: Standalone vanilla stack that works seamlessly with local or remote n8n instances without heavy build tooling.
